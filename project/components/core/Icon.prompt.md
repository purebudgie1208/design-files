Renders a single 1.5px monoline outline glyph from Lucide — the only icon source in this system.

```jsx
<Icon name="arrow-up-right" size={16} />
```

Requires `<script src="https://unpkg.com/lucide@0.469.0/dist/umd/lucide.js"></script>` on the page. Always currentColor and never filled; brand set is graduation-cap, landmark, globe, book-open-text, chevron-down/left/right, arrow-up-right, arrow-right, search. Never use emoji in place of an icon.
