Typographic stand-in for the brand mark. **No crest artwork ships with this system** — the University of Oxford crest was not supplied, so never draw one; use this instead.

```jsx
<Wordmark size={40} />
<Wordmark size={180} tone="silver" />
<Wordmark size={160} tone="translucent" />
```

`translucent` is the oversized hero watermark; `silver` is the footer treatment that bleeds off both page edges.
