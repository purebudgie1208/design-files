The site's only CTA — a navy pill with a white circular arrow badge on its right edge ("Learn more", "Send Message", "Login").

```jsx
<Button>Learn more</Button>
<Button variant="ghost" icon="arrow-right">Read more</Button>
<Button showIcon={false}>Login</Button>
```

Variants: `primary` (Oxford Blue, default), `ghost` (white chip, hairline border), `inverse` (for near-black sections). Sizes sm/md/lg. Label is sentence case and verb-first.
